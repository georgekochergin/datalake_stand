## Журнал

DDL не меняется. `ingestion.airflow_tasks_log` сохраняет append-only события
с `process_id`, источником, FQN, целевой таблицей, временем и статусом.
START повторяется на каждой попытке. END означает успешный `load`, FAILED —
окончательную неудачу. Пропуски событий допустимы, источник истины о состоянии
задачи — Airflow. Инкрементальный реестр остаётся источником истины о партиях.
