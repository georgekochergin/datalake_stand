# План

Конституция прочитана. Анализ выполнен через graphify. Изменения существующих контрактов требуют синхронного обновления YAML, генератора, оператора, приложений, тестов и документации.

1. Общая строгая валидация разрешённого JSON-контракта и канонического типа.
2. Разрешение lookback в парсере манифеста; передача объекта генератором и оператором.
3. Проверка JDBC-типа отдельно от агрегатов новой партии и при retry.
4. Обновление конфигураций и проверок без совместимости со старыми флагами.
5. Документация, полный изолированный прогон, актуализация графа.

Риски: Oracle NUMBER и DATE не совпадают с одноимёнными представлениями других СУБД; фактическое сопоставление выполняет диалект. Повторная проверка метаданных не фиксирует схему на время чтения.
