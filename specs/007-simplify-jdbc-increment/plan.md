# План реализации

1. Упростить выбор колонки разбиения и добавить необязательную булеву проверку в контракт загрузки.
2. Считать границы одним агрегатным запросом, составленным по режиму чтения. Для новой инкрементальной партии вычислять границы от той же заблокированной ревизии состояния, с которой партия будет сохранена. Для повтора использовать сохранённое окно.
3. Обновить диагностику и архитектуру. Проверить формы запросов, пустые срезы, правила `NULL` и оба диалекта.
