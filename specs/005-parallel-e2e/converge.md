### Раздельные бюджеты и заключительная приёмка

По решению ревью 6953162362 одиночный режим ограничен 420 секундами,
параллельный — 600 секундами. Реализованы все три ускорения: PostgreSQL
проверяется третьей фоновой ветвью, temporal/schema стартуют до реестра,
ранний POST activate перекрывается с ожиданием готовности Airflow.
Результат activate проверяется, штатный оператор DAG сохранён.
Пересечений состояния не выявлено: реестр фильтрует выбранный source_id,
temporal использует e2e source_id, PostgresTests создают отдельную БД.

Приёмка выполнена без изменения исполняемых файлов между запусками,
с обычной сборкой из тёплого кэша, без TEST_SKIP_BUILD:
