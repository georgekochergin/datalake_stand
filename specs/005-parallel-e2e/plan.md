## Решение

Конституция прочитана. Python без комментариев, изоляция от живого стенда,
ветка `georgekochergin/parallel-e2e`, мерж только пользователем.
Внешний согласованный план используется как исходное исследование, без
повторного профилирования. Текущие проверки Spark retry guard, добавленные
после плана, сохраняются и выполняются один раз.

1. Вынести профиль объёмов и подготовку тестового дерева в Python-модуль.
   Фильтровать конфигурацию источников, миграции и DAG. Проверять изменение
   retries через AST, не менять исходные production-файлы.
2. Параметризовать runtime-проверки источником, перенести статику в unit.
   Сократить только согласованные шаги, ускорить опрос и объединить SQL.
3. Перестроить shell-оркестратор: общие теги образов, однократная сборка,
   два фоновых стека, отдельные логи и очистка, агрегация статусов и времени.
4. Переименовать скилл в full-testing, обновить действующие ссылки и правила.

## Проверки

- Unit-тесты профиля, фильтрации, тестовых retries и статических контрактов.
- Shell syntax, Compose config обоих стеков, `git diff --check`.
- Итоговый параллельный e2e после увеличения памяти Docker VM.
  На старте работы доступно 16748032000 байт; это меньше порога.
- Граф обновляется по скиллу graphify перед коммитом. Коммит и публикация
  требуют отдельного разрешения.
