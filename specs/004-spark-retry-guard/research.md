## Решения

- Master-only принят после экспериментов без pause. Опрос workers отвергнут: необходимость не подтверждена, он расширяет гарантию и механизм сверх согласованного решения.
- Проверка completedapps обязательна: killEnabled=false даёт HTTP 200 без остановки.
- Один kill на исходный ID. Новый ID того же target означает нарушение единственного владельца, а не новый цикл очистки.
- HTTP Connection отдельно от submit. Общий префикс `spark_main_`, без extra-связей. Согласованность обеспечивается конфигурацией и проверками.
- Callback не барьер: доставка после SIGKILL недетерминирована, on_execute может подавлять исключения.
- Не вводится PID management. После kill обычный Python driver может продолжаться, commit не отменяется.
