# Единое хранение моментов времени в raw

- Oracle `TIMESTAMP WITH [LOCAL] TIME ZONE` и SQL Server `datetimeoffset` записываются как Iceberg `timestamptz`. Например, `15:30 +03:00` и `12:30 +00:00` обозначают один момент.
- Исходное смещение не хранится. Точность данных в Iceberg — до микросекунд. Позиция инкремента сохраняет исходную точность.
- Даты и дата-время без зоны сохраняют текущие типы и значения. `__load_dttm` остаётся `timestamptz`.
- Правило действует для полной, инкрементальной и snapshot-загрузок. Миграция существующих таблиц не входит в задачу.
